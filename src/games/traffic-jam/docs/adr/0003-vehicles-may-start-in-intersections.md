# Vehicles may start inside an Intersection

The first plan kept Vehicles out of Intersections. But then a Vehicle on a crossing Street is never on anyone else's Route, and crossing traffic never blocks, which empties out Chapter 2 ("a crossing") and most of the gridlock. So Vehicles may start with any part inside an Intersection, which is the traffic jam the game is named for. A truck or bus may not sit wholly inside one, because it would look parked across both Streets.
