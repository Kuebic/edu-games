# Only a truck or bus tail may start in an Intersection

This replaces 0003. A car sitting in an Intersection, or a truck with its front in one, was confusing: with a turn Arrow it looks like it is already turning there, and a car a little behind the middle seemed to belong to that Intersection when its Route actually turned at the next one. So no Vehicle's front cell starts in an Intersection. A truck or bus tail still may, and that tail is now the only thing that can block a crossing Street's traffic. Without it Chapter 2 ("Crossings") would have nothing to teach, so trucks now appear from Chapter 2 on, and the Trucks Chapter is no longer the first place a child sees one.
