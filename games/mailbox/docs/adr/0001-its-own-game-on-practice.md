# Its own Game, on Practice

Matching lowercase letters to capitals could have been a Way in Find It (which has Letters) or a Topic in Tidy Up (which sorts). We made Mailbox a Game of its own. The research puts sorting first: a lowercase letter into a bin wearing its capital, which for c o s is nearly the same picture, then finding the lowercase letter that goes with a capital. Both need the same things neither Game has: a font of their own with a single-story a and g (ADR 0002), one baseline for both cases, Hints that fade (ADR 0004), and Names that are recordings (ADR 0003). Find It asks four to six-year-olds with the Voice; Tidy Up sorts by rules the child already has words for.

It's a Practice Game (the site's ADR 0014) with one Topic, because letters are learnt by going over them and a grown-up will change which ones come up between sessions. The research's order is the Ranges, Same to Tricky, not a path of Levels, since the user's child outgrows scaffolds faster than any fixed path. Sort plays on the site's sorting screen and Find on its asking screen (site ADRs 0016 and 0017).

We called it Mailbox, with the letters posted, rather than "mama and baby letters": that story fits c and o but not A and a, and it teaches that size makes a letter lowercase.
