# The Names are clips, and the only words

As in Tidy Up and Piggy Bank, there's no Voice: browser speech is silent on the user's Linux computer, and the user can't record voices. The 26 letter Names are one speaker, tim.kahn's "The Alphabet" on Freesound (CC BY 4.0), a US voice, made by `npm run game mailbox names`. Commons has all 26 too, but from about ten speakers, and no CC0 speaker has them all. Each recording runs on after the name with breaths and room noise, so the task keeps the name up to its first pause.

The Name is the only word the Game says. A capital and its lowercase share it, and that shared name is what links them, so the Game never says "capital", "lowercase", "big" or "little". A Mailbox's Name is said as the first Card goes into it a Round, not on every right drop (Tidy Up's ADR 0004), and in Find only the Ask says one (Piggy Bank's ADR 0004).
