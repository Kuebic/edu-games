# Credits

## Names

Made by `npm run game mailbox names`: the name only, trimmed of silence and the breaths after it, levelled and faded, as MP3. Changed recordings under CC BY stay under CC BY.

| Files | Source | Author | Licence |
| --- | --- | --- | --- |
| a.mp3 to z.mp3 | [The Alphabet](https://freesound.org/people/tim.kahn/packs/4371/), Freesound sounds 67712 (a.wav) to 67737 (z.wav), their previews | tim.kahn (Tim Kahn) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

Speech recognition (faster-whisper, small.en) heard each shipped clip as its letter. A person hasn't listened to them yet.

## Letter font

`mailbox-letters.woff2` is made by `npm run game mailbox font` from Andika Bold 6.101, Copyright (c) 2004-2022 SIL International, with Reserved Font Names "Andika" and "SIL", from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/andika). It keeps only A to Z and a to z, puts Andika's tailed l (its cv39) in the plain l's place, and is renamed "Mailbox Letters", since a Modified Version may not use the Reserved Font Names. It is under the SIL Open Font License 1.1, in [andika-ofl.txt](./andika-ofl.txt).
