# A right drop says nothing new

The user found it annoying that a Bin said its name again every time a Thing went in right, the same thing they found in Piggy Bank's Find (its ADR 0004). A child who has just heard "animals" as the crate opened, or "red" as the first block went in, doesn't need it eight more times; repeats bored the user's 3-year-old in the first playtest. So a right drop says its Word only for the first Thing into that Bin in a Round, and in Kinds, where the crates already said their names as the Round opened, not at all. After that it's the landing sound alone. Words still come when they help: a tap on a Thing, a Miss (its name, then its group), and from the second nudge. The CDC's "name each piece as it goes in" is now the grown-up's, as the note says. The sorting screen tells a Game whether a drop is the first into its Bin (`landed(thing, first)`, site ADR 0016), so Piggy Bank's Sort follows the same rule.
