# A new Name starts My name fresh, and New letters never move

Saved progress keeps Done by Group and Level position (ADR 0012), and a My name Level is a Name letter, so SAM's second Level is A while SARA's is also A but TOM's is O. When a grown-up changes the Name, My name's Done marks are cleared, and New letters' stay. New letters is always all eight letters, even ones in the Name, so its positions never change: BEN's B is met twice. We rejected keeping Done per letter in the Game's own slot, which would carry S and A over from SAM to SARA, because it works around the shared Saved progress for a change a grown-up makes about once. We rejected leaving Name letters out of New letters, since it would make that Group's Levels move too.
