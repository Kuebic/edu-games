# A grown-up adds Words to spell after the Name

The Name was the only word a child spelt. Their grown-up asked to add the other words a three-year-old wants to spell: Mama, Dada, a sibling's name, spelt the way the family says them. So My name became My words: a Level per word, the Name first, then up to ten Words typed in one Grown-up Corner box between commas, each a Spell like the Name's. The Voice says each word as typed; the Name line, cards and Choices use its capitals, as with the Name. All their letters are Met letters in New letters. A word with no letters, or spelt the same as one before it, is left out, so no two Levels are the same. The Letter board still colours only the Name letters, since they're the child's own.

Done is still kept by position in the shared Saved progress (ADR 0002). A Word added at the end leaves every earlier word where it was, so My words keeps its Done marks; any other change (a word edited, moved, taken away, or a Name typed in front of Words) starts My words fresh, and New letters stays. We rejected one text box per Word with add and remove buttons (a new shared Corner row for a list a grown-up types once) and keeping Done per spelling in the Game's slot, rejected in ADR 0002 for the same reason. My words stays Group 0 and New letters Group 1, so old saves keep their marks: a Done on the Name's Spell is still Level 0.
