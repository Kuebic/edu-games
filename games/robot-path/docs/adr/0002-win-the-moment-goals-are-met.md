# A Level is won the moment every Goal is met

The Run stops and celebrates as soon as the last Goal is met, even if Commands are left over. The stricter rule, where the Program has to end exactly on the Goal, teaches tighter Programs, but it gives a four-year-old a robot standing on the flag and no win, which reads as the game being broken. Tight Programs are rewarded by the Sparkle instead. A Program with extra Commands after the win still counts all its Slots, so it can miss the Sparkle.
