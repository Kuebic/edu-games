# Placeholder Skins drawn in code

The three Skins (Garden, Planet, Sea) are SVG markup in `src/skins.ts`, and the sounds are Web Audio notes in `src/sound.ts`, so the game downloads no art or audio and fits well under its 500KB budget. The Sea Skin stands in for the third one he asks for. Level data never mentions a Skin, so final art can replace a Skin's markup without touching a Level. Bip, the helper in Fix-it Levels, is one character across all Skins, so a Skin swap doesn't change who wrote the broken Program.
