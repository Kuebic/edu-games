# No scores, timers or failure

As in Snack Math: no points, Sparkles, timers or lives, and every finished Round counts however many picks were wrong. A wrong pick is named and, on a Tray, counted along, then the question is asked again with that Choice dimmed, so a child can never be stuck. The player is a pre-reader being introduced to the symbols; the aim is to keep them looking, not to grade them.
