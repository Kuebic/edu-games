# Nobody loses the race

Game Shelf Games have no lose state, but a race has a winner. Hop Race keeps the race and drops the losing: a Race is done when the Hopper gets Home, whoever got there first. A Friend that gets Home first says so ("Frog is home! Keep hopping!") and waits, and the Hopper's turns go on alone.

We considered rigging the Spinner so the Hopper always wins, and dropping the Friend. Rigging makes Who's ahead always the Hopper, which teaches nothing, and without a Friend there's nothing to compare. The Friend's turns also give the child more numbers to hear without tapping.
